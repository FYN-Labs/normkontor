# Normkontor enterprise pack

This pack turns the open ruleset into a bounded client offer without pretending
that documentation is a deployed control system.

- control-model.md describes decision stages and ownership.
- assurance-architecture.md describes the planned Review product contract.
- privacy-and-regulated-controls.md frames data and regulatory work.
- academy-and-rollout.md defines the training and pilot offer.
- claims-ledger.md separates current fact, service on request, planned product,
  and prohibited claim.

Normkontor is a product brand of FYN Labs LLC. Client-specific legal analysis,
DPIA, works-council involvement, security approval, hosting proof, and release
authority remain with their named owners.

# Public claims ledger

Checked: 2026-08-26. Owner: FYN Labs.

## FACT — currently true

- Normkontor is a public FYN Labs product brand and repository.
- `standard/KERNEL.md` is the sole normative governance owner.
- `standard/contract.json` is a machine-readable, non-normative index of the
  Kernel contract.
- Linear is the sole execution ledger. A governed work item has exactly one
  controlled role label, a verified assignee mapping, and evidence references;
  Linear is not memory, policy, or an authority source.
- Merge, deploy, publish, spend, production, and Linear Done require the
  verified human Decision Owner and a valid Decision Receipt for the exact
  host, organization, action, subject, time window, and immutable evidence.
- 3A COD3X is an instruction-only open-source source candidate with two skills.
- Codex and Claude marketplace manifests resolve to the same plugin files.
- The Codex and Claude Code source adapters import Kernel `1.0.0` and forbid
  writing host settings or hooks.
- The Command EVE source adapter confines product permissions and credits to
  the product; they do not grant repository or Linear authority.
- The Linear source adapter maps the sole execution ledger and forbids
  worker, reviewer, audit, or controller roles from setting Done.
- The repository contains static source/package tests and a public eval corpus.
- Static conformance checks inspect only their declared public source set; they
  do not observe runtime behavior or prove the absence of prohibited actions.
- The public repository contains no hot memory and no capture hooks.
- The doctrine requires a blind two-arm gate for company-classified material
  architecture, routing, eval, CAO, and audit packages.
- Human and CI authority remain outside the plugin.
